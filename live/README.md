# Packing Station (live)

A CCN Terminal page connected to the live service in the Wolfram Cloud, `https://www.wolframcloud.com/obj/ccn2/TerminalKernel`. Sign in with a worker passkey added by the owner (`terminalAddWorker`); the Job menu lists the jobs saved in the authoring tool (`../author/`). Every click is reported to the service. For test mode, with no requests, use `../demo/`.

- `index.html` — the page
- `notes.md` — production notes
- `terminal-data.json` — the page's settings, for reuse
- `manifest.webmanifest`, `sw.js`, `icons/` — install files
