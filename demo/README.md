# Packing Station

A CCN Terminal page, built as a **demonstration in test mode**: no requests are made, the sub-tasks and job specifics are canned, and the passkey is `123`. The dashed panel at the bottom plays the manager's side. The logo is a placeholder (the CCN icon). Jobs saved in the job-authoring tool's test mode (https://lossofgenerality.github.io/terminal/author/?mock=1) in the same browser appear in its Job menu. Open `index.html` (best from an https:// site such as GitHub Pages, so that Install works). Add `?mock=1` to the address for canned sub-tasks and no requests.

- `index.html` — the page (everything built in; sub-tasks are fetched from each task's address)
- `notes.md` — production notes
- `terminal-data.json` — the page's settings, for reuse
- `manifest.webmanifest`, `sw.js`, `icons/` — install files
