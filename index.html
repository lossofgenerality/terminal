CCN Terminal — Builder

Describe an app here and the builder writes it as one standalone page: a pulldown of tasks, a passkey sign-in, one task per session, with a sign-out that waits until every sub-task of it is ticked, and a message box. Each task's sub-tasks are fetched from its own address when the task is chosen.

2 · Tasks

One task per line. Give its address after a bar (Task name | https://…), or leave the address out to make it from the pattern below. The address must return the sub-tasks: a JSON list of strings, a JSON object holding such a list under subtasks or items, or plain text with one sub-task per line.
#TaskAddress of its sub-tasks

3 · Sign-in and sign-out

The loaded specification already holds a passkey hash; leave both boxes empty to keep it.
One task per session: after signing in, the person chooses one task, and may sign out only once every sub-task of it is ticked. Signing out records the task as done, so the next sign-in offers one task fewer. With the service, the service keeps that record (see the README); with the in-page check, this device does.
